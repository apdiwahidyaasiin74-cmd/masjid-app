2. TALLAABOOYINKA LAGU GAYNAYO ONLINE (LIVE SERVER DEPLOYMENT):
   ---------------------------------------------------------------------
   Tallaabada 1: Soo raridda Faylasha (Upload Files)
   - Ka samee ZIP folder-ka mashruuca (shiine).
   - Ka dhig cPanel / VPS / Hostinger ama Server-ka aad iibsatay.
   - Extract ka dheh faylasha ku jira cPanel "public_html" ama galka server-ka.

   Tallaabada 2: Habaynta Faylka .ENV ee Server-ka Online-ka ah
   - Badal faylka .env xogtiisa:
     APP_ENV=production
     APP_DEBUG=false
     APP_URL=https://domainkaaga.com   (ama IP-ga server-ka)
     
     DB_CONNECTION=sqlite             (ama mysql haddii aad MySQL isticmaalayso)
     # Haddii aad MySQL isticmaalayso:
     # DB_HOST=127.0.0.1
     # DB_DATABASE=shiine_db
     # DB_USERNAME=user_db
     # DB_PASSWORD=password_db

   Tallaabada 3: Shaanxinta & Xanta Server-ka (Terminal / SSH Command)
   - Ku wada amarradan terminal-ka Server-ka:
     php artisan key:generate
     php artisan storage:link
     php artisan migrate:fresh --seed   (ama php artisan migrate)
     php artisan config:cache
     php artisan route:cache
     php artisan view:cache
